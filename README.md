# AX 스킬셋

UX 기획자를 위한 AI 프롬프트 관리 도구.
설치 없이 URL 접속만으로 사용합니다.

## 바로 사용하기

**🔗 https://blovenee-sudo.github.io/Skillset/**

URL을 열면 바로 사용할 수 있습니다. 별도 설치가 필요 없습니다.

## 스킬 사용 방법

### 1. 스킬 선택 → 스킬 복사

사이드바에서 스킬을 클릭하면 상세 패널이 열립니다.
**스킬 복사** 버튼을 누르면 슬래시 명령어와 지침이 함께 클립보드에 복사됩니다.

### 2. 사용 중인 LLM에 붙여넣기

복사한 내용을 ChatGPT, Claude.ai, Gemini 등 어떤 LLM에든 붙여넣으면
해당 스킬의 지침을 인식하고 실행합니다.

```
/spec-analysis         ← 슬래시 명령어
                       ← 지침 프롬프트 전체
다음 제품/기능 스펙을 읽고 정리하세요...
```

이후 분석할 내용을 이어서 입력하면 됩니다.

### Claude Code · Cursor · Copilot 사용자

`run.command`(Mac)로 스킬을 한 번 등록해두면 이후부터는 슬래시 명령어만 입력해도 지침이 즉시 실행됩니다.

```
/spec-analysis   ← 명령어만 입력해도 지침 자동 실행
```

> 스킬 복사 후 앱 안에서 이 안내가 자동으로 표시됩니다.

## Dock / 작업 표시줄에 앱으로 설치 (선택)

브라우저에서 앱으로 설치하면 Dock이나 작업 표시줄에서 바로 실행할 수 있습니다.

### macOS

| 브라우저 | 방법 |
|----------|------|
| Chrome | 주소창 오른쪽 `⊕` 아이콘 클릭 → **설치** |
| Edge | 오른쪽 상단 `···` → **앱** → **이 사이트를 앱으로 설치** |
| Chrome / Edge (공통) | 오른쪽 상단 `⋮` / `···` → **전송, 저장, 공유** → **앱으로 설치** |
| Safari | 공유 버튼 `□↑` → **Dock에 추가** |

### Windows

| 브라우저 | 방법 |
|----------|------|
| Edge (권장) | 오른쪽 상단 `···` → **앱** → **이 사이트를 앱으로 설치** → 작업 표시줄에 고정 |
| Chrome | 주소창 오른쪽 `⊕` 아이콘 클릭 → **설치** |
| Chrome (아이콘 없을 때) | 오른쪽 상단 `⋮` → **전송, 저장, 공유** → **앱으로 설치** |

> 설치 후 시작 메뉴 또는 작업 표시줄에서 바로 실행됩니다.

## 앱 삭제(제거) 방법 (선택)

앱으로 설치한 경우에도 실제 프로그램이 설치되는 것이 아니라 브라우저 기반 앱(PWA)입니다.

### macOS

Chrome

1. 주소창에 chrome://apps 입력
2. AX 스킬셋 우클릭
3. Chrome에서 제거 선택

또는

1. Chrome 실행
2. 오른쪽 상단 ⋮ → 전송, 저장, 공유
3. 앱 관리
4. AX 스킬셋 선택 후 제거

Edge

1. 주소창에 edge://apps 입력
2. AX 스킬셋 선택
3. 제거(Uninstall) 클릭

Safari (Dock에 추가한 경우)

Dock에서 아이콘 우클릭 → 옵션 → Dock에서 제거

### Windows

Chrome

1. 주소창에 chrome://apps 입력
2. AX 스킬셋 우클릭
3. Chrome에서 제거

Edge

1. 주소창에 edge://apps 입력
2. AX 스킬셋 선택
3. 제거(Uninstall)

데이터까지 완전히 삭제하려면

앱 제거 후 브라우저의 사이트 데이터도 삭제하세요.

* Chrome: 설정 → 개인정보 및 보안 → 인터넷 사용 기록 삭제
* Edge: 설정 → 개인정보, 검색 및 서비스 → 검색 데이터 지우기

앱만 삭제하면 일부 데이터가 브라우저에 남아 있을 수 있습니다. 완전 초기화를 원하면 사이트 데이터도 함께 삭제하세요.

## 데이터 저장 방식

URL로 접속해 사용하는 경우, **사용자 컴퓨터에 어떤 파일이나 폴더도 생성되지 않습니다.**
모든 데이터는 브라우저 내부 저장소(localStorage)에만 저장됩니다.

```
사용자 컴퓨터
├── Documents/   ← 아무것도 생성되지 않음
├── Downloads/   ← 아무것도 생성되지 않음
└── 브라우저 내부
    └── localStorage  ← 세션·스킬·프로젝트가 여기에 저장됨
```

| 상황 | 데이터 |
|------|--------|
| 같은 기기, 같은 브라우저로 재접속 | 유지 ✅ |
| 브라우저를 껐다 켜도 | 유지 ✅ |
| 다른 브라우저로 접속 | 초기화 ❌ |
| 다른 기기에서 접속 | 초기화 ❌ |
| 브라우저 캐시·사이트 데이터 삭제 | 초기화 ❌ |

> 앱을 삭제하려면 브라우저에서 **사이트 데이터 지우기**만 하면 됩니다.
> 기기를 바꾸거나 브라우저가 초기화된 경우, 기본 스킬은 자동 복원되며
> 사용자가 추가한 스킬·프로젝트는 다시 설정이 필요합니다.
