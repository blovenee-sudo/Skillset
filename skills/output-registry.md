# AX 스킬셋 산출물 레지스트리

각 스킬에서 후속 산출물로 제공할 수 있는 파일 유형과 생성 기준을 정의합니다.
`/generate-output` 스킬이 이 레지스트리를 참조하여 적합한 산출물을 생성합니다.

---

## OUTPUT-01. HTML 분석 리포트

**적용 스킬:** 전체 (s0~s10)
**설명:** 분석 결과 전체를 다크 테마 카드형 HTML 파일로 변환. 인쇄·PDF·MD 저장 지원.
**생성 기준:** `skill_report_template.html` 기반. `<style>`·`<script>` 블록 수정 금지. 섹션마다 `.section-card` 사용. 핵심 요약은 `.summary-grid`, 체크리스트는 `.checklist-item`(인터랙티브), 표는 `.styled-table`.
**출력:** 완성된 HTML 코드블록 + `~/Desktop/[프로젝트명]-report.html` 저장

## OUTPUT-02. 자료요청명세서 초안 (Material Request Draft)

**적용 스킬:** s1 (스펙 분석), s5 (기능 정의서), s9 (사이트 기획안)
**설명:** 프로젝트 수행에 필요하다고 판단되는 자료를 분석 결과 기반으로 역추론하여 작성한 초안. 실제 존재 확인된 자료 목록이 아님.
**생성 시 포함 항목:**
1. 자료요청명세서 초안 (자료명 / 형식 / 용도 / 요청 부서 / 기한)
2. 자료 수급 체크리스트
3. 부서별 요청 목록
4. 자료 다운로드 가이드
5. 파일명 규칙
6. 승인자 매트릭스
7. 자료 수급 우선순위
**권장 프로젝트:** 홈페이지 구축·리뉴얼, 채용·브랜드 사이트, 플랫폼·서비스·관리자 시스템·모바일 앱 구축
**제외 프로젝트:** 단순 기능·버그·문구 수정, 단일 페이지·이벤트 페이지·운영성 유지보수

## OUTPUT-03. 기능 정의서 초안

**적용 스킬:** s1 (스펙 분석)
**설명:** 스펙 분석 결과를 개발자·QA에 넘길 수 있는 기능 정의서 형식으로 변환.
**생성 시 포함 항목:**
- 기능 ID / 기능명 / 목적
- 입력·출력 / 상태 전이
- 정상 케이스 (Happy Path)
- 엣지케이스·예외 처리 (빈 상태, 권한 없음, 네트워크 오류, 중복)
- 미결 정책 항목
- 비기능 메모 (접근성, 성능)

## OUTPUT-04. 인사이트 슬라이드 초안

**적용 스킬:** s2 (벤치마킹), s6 (휴리스틱 평가)
**설명:** 분석 결과를 이해관계자에게 공유할 수 있는 슬라이드 구조(텍스트 기반)로 정리.
**생성 시 포함 항목:**
- 표지 (제목 / 분석 대상 / 날짜)
- 분석 배경 및 목적
- 핵심 인사이트 (슬라이드 1장당 인사이트 1개)
- 시사점 및 제안
- 요약

## OUTPUT-05. 개선 액션 목록

**적용 스킬:** s6 (휴리스틱 평가), s8 (리뷰 코멘트)
**설명:** 발견된 문제를 실행 가능한 개선 작업 목록으로 변환.
**생성 시 포함 항목:**
- 우선순위 (P1/P2/P3)
- 개선 항목 / 현재 문제 / 제안 방향
- 담당 (UX·개발·기획)
- 예상 난이도 (상·중·하)
- 참고 근거 (관련 원칙 or 코멘트 번호)

## OUTPUT-06. 위키 업로드용 회의록

**적용 스킬:** s7 (회의록)
**설명:** 정리된 회의록을 사내 위키(Confluence·Notion 등) 업로드에 적합한 구조로 재포맷.
**생성 시 포함 항목:**
- 메타 정보 (일시 / 참석자 / 자료 링크)
- 결정사항 (번호 목록)
- 액션아이템 (담당 / 기한 / 완료 조건 표)
- 열린 이슈 / 다음 논의 안건
- AI 요약 (3줄)

- 네비게이션 주의사항
