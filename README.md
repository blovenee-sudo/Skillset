## Dock / 작업 표시줄에 앱으로 설치 (선택)

브라우저에서 앱으로 설치하면 Dock이나 작업 표시줄에서 바로 실행할 수 있습니다.

### macOS

| 브라우저 | 방법 |
|----------|------|
| Chrome | 주소창 오른쪽 `⊕` 아이콘 클릭 → **설치** |
| Edge | 오른쪽 상단 `···` → **앱** → **이 사이트를 앱으로 설치** |
| Chrome / Edge (공통) | 오른쪽 상단 `⋮` / `···` → **전송, 저장, 공유** → **앱으로 설치** |
| Safari | 공유 버튼 `□↑` → **Dock에 추가** |

### Windows

| 브라우저 | 방법 |
|----------|------|
| Edge (권장) | 오른쪽 상단 `···` → **앱** → **이 사이트를 앱으로 설치** → 작업 표시줄에 고정 |
| Chrome | 주소창 오른쪽 `⊕` 아이콘 클릭 → **설치** |
| Chrome (아이콘 없을 때) | 오른쪽 상단 `⋮` → **전송, 저장, 공유** → **앱으로 설치** |

> 설치 후 시작 메뉴 또는 작업 표시줄에서 바로 실행됩니다.

## 데이터 저장 방식

URL로 접속해 사용하는 경우, **사용자 컴퓨터에 어떤 파일이나 폴더도 생성되지 않습니다.**
모든 데이터는 브라우저 내부 저장소(localStorage)에만 저장됩니다.

```
사용자 컴퓨터
├── Documents/   ← 아무것도 생성되지 않음
├── Downloads/   ← 아무것도 생성되지 않음
└── 브라우저 내부
    └── localStorage  ← 세션·스킬·프로젝트가 여기에 저장됨
```

| 상황 | 데이터 |
|------|--------|
| 같은 기기, 같은 브라우저로 재접속 | 유지 ✅ |
| 브라우저를 껐다 켜도 | 유지 ✅ |
| 다른 브라우저로 접속 | 초기화 ❌ |
| 다른 기기에서 접속 | 초기화 ❌ |
| 브라우저 캐시·사이트 데이터 삭제 | 초기화 ❌ |

> 앱을 삭제하려면 브라우저에서 **사이트 데이터 지우기**만 하면 됩니다.
> 기기를 바꾸거나 브라우저가 초기화된 경우, 기본 스킬은 자동 복원되며
> 사용자가 추가한 스킬·프로젝트는 다시 설정이 필요합니다.
