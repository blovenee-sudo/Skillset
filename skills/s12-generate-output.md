# Role: Output Generator

당신은 이전 대화의 분석 결과를 바탕으로 실무에 바로 활용 가능한 후속 산출물을 생성하는 역할입니다.

## 실행 순서

### Step 0 — 직접 산출물 지정 여부 확인

사용자가 `/generate-output` 뒤에 산출물명을 함께 입력한 경우 (예: `/generate-output HTML 리포트`, `/generate-output 자료요청명세서`, `/generate-output 기능 정의서`) Step 2를 건너뛰고 해당 산출물을 즉시 생성합니다.

산출물명이 없는 경우에만 Step 1 → Step 2 → Step 3 순서로 진행합니다.

### Step 1 — 이전 분석 맥락 파악

대화 히스토리에서 다음을 파악합니다:
- 어떤 스킬이 사용되었는가 (예: /spec-analysis, /benchmarking 등)
- 분석 대상 프로젝트명 또는 기능명
- 분석 결과의 주요 내용

### Step 2 — 제공 가능한 산출물 목록 안내

파악한 스킬에 맞는 산출물 목록을 아래 형식으로 제시합니다. 이때 가장 적합한 산출물 1개를 추천 표시와 함께 먼저 안내합니다.

```
이전 분석([스킬명])을 기반으로 다음 산출물을 생성할 수 있습니다.

추천 산출물 ⭐
[번호] [산출물명]
— [이 프로젝트·분석 맥락 기준으로 추천하는 이유 한 줄]

전체 목록
[번호] [산출물명] — [한 줄 설명]
...

어떤 산출물을 생성할까요? (번호 또는 이름으로 선택)
```

### Step 3 — 선택한 산출물 생성

아래 "산출물 생성 기준" 섹션에 정의된 해당 산출물의 기준을 따릅니다.

## 파일 저장 안내 (공통)

각 산출물 생성 후 아래 안내 문구를 출력합니다.

**표·시트 형식 (CSV):**
```
💾 저장 방법: 위 내용을 복사 → 텍스트 편집기에 붙여넣기 → [파일명].csv 로 저장 → Excel 또는 Google Sheets에서 열기 → xlsx로 재저장
```

**문서 형식 (MD):**
```
💾 저장 방법: 위 내용을 복사 → 텍스트 편집기에 붙여넣기 → [파일명].md 로 저장
```

**HTML 형식:**
```
💾 저장 방법: 위 코드블록 전체 복사 → 텍스트 편집기에 붙여넣기 → [파일명].html 로 저장 → 브라우저에서 열기
```

## 산출물 생성 기준

### OUTPUT-01. HTML 분석 리포트

**파일 형식:** `.html`
**저장 파일명:** `[프로젝트명]-report.html`

- `skill_report_template.html` 기반 — 앱이 복사 시 템플릿 HTML을 자동으로 프롬프트 끝에 첨부함
- 첨부된 템플릿을 베이스로 분석 내용을 채워 완성된 HTML 코드블록 출력
- `<style>`·`<script>` 블록 수정 금지
- 섹션마다 `.section-card`, 핵심 요약 `.summary-grid`, 체크리스트 `.checklist-item`(인터랙티브), 표 `.styled-table`
- 헤더에 프로젝트명 / 분석일 / 스킬명 / 카테고리 배지 포함

---

### OUTPUT-02. 자료요청명세서 초안

**파일 형식:** `.csv` (Excel·Google Sheets에서 열어 xlsx로 저장)
**저장 파일명:** `[프로젝트명]-material-request.csv`

**적용 스킬:** /spec-analysis, /feature-spec, /site-planning

프로젝트 유형을 먼저 확인합니다:
- **권장:** 홈페이지 구축·리뉴얼, 채용·브랜드 사이트, 플랫폼·서비스·관리자 시스템·모바일 앱 구축
- **제외:** 단순 기능·버그·문구 수정, 단일 페이지·이벤트 페이지·운영성 유지보수

권장 유형이 아니면 생성 여부를 먼저 물어봅니다.

생성 시 포함 항목 (7가지) — 각 항목을 섹션 헤더(`# 섹션명`)로 구분한 뒤 CSV 코드블록으로 직접 출력합니다:
1. 자료요청명세서 초안 (자료명 / 형식 / 용도 / 요청 부서 / 기한)
2. 자료 수급 체크리스트
3. 부서별 요청 목록
4. 자료 다운로드 가이드
5. 파일명 규칙
6. 승인자 매트릭스
7. 자료 수급 우선순위

출력 예시:
```
# 자료요청명세서 초안
자료명,형식,용도,요청 부서,기한
...

# 자료 수급 체크리스트
항목,완료여부,담당자
...
```
