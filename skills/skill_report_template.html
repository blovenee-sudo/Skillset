주문 목록 화면
· 최근 3개월 주문 내역 기본 노출, 전체/배송중/완료/취소 필터 제공
· 페이지당 20건 노출, 무한 스크롤 또는 페이지네이션
[추정] 주문 없을 때 빈 상태 UI 필요
주문 상세 화면
· 주문번호 / 상품명 / 수량 / 결제금액 / 배송지 / 배송 추적 링크 포함
[추정] 타인 주문번호 직접 URL 접근 시 권한 차단 처리 필요
주문 취소
· 취소 사유 선택(드롭다운) + 자유 입력(선택) 후 취소 요청
· 완료 상태 주문에서 취소 버튼 비활성화
⚠️ 3. 모호성 및 확인 필요 항목 (Gap Analysis)
# 항목 문제 설명 결정 필요 방향
1 조회 기간 3개월 이전 주문 조회 가능 여부 미명시 기간 선택 필터 제공 여부 정책 결정 필요
2 취소 가능 조건 어떤 배송 상태까지 취소 가능한지 불명확 배송 시작 전까지 가능 여부 정책 확인
3 부분 취소 다수 상품 묶음 주문 시 일부만 취소 가능 여부 없음 부분 취소 지원 범위 결정 필요
✅ 4. 최종 검수 체크리스트
🔲 조회 기간: 3개월 이전 주문도 조회 가능해야 합니까?
⚠️ 빈 상태 UI: 주문 내역이 없을 때 안내 화면이 기획에 포함됩니까?
✅ 권한 체크: 타인의 주문번호 직접 접근 시 차단되어야 한다는 것에 동의하십니까?
❌ 부분 취소: 현재 기획서에 부분 취소 관련 내용이 누락되어 있습니다. 추가 검토 필요.
